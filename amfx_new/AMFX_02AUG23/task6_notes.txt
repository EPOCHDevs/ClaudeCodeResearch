Task 6: RBOB Gasoline 2023 Bull Flag
=====================================
Status: DONE (definition created, with documented limitation)

Reference: page_03_img_01.jpeg
Original: TradingView candlestick chart of RBOB gasoline (Dec 2022-Aug 2023)
          with a bull flag pattern drawn (converging diagonal trendlines)

Reproduction approach:
- Asset: RB-Futures (EOD data available from 1984)
- The TradingView chart panel natively displays candlesticks for
  futures assets when using market_data_source()
- futures_continuation() with NoAdjustment provides continuous
  front-month price levels
- Dashboard xy_lines chart shows close + 20d/50d MAs with
  horizontal reference_lines at key levels (2.90, 2.60, 2.20)
- Momentum chart (20d and 60d ROC) shows rally acceleration

What IS reproduced:
- RBOB gasoline price for the exact period (Dec 2022-Aug 2023)
- TV chart candlesticks (native)
- Key horizontal levels: flag high ($2.90), flag low ($2.60),
  flag pole base ($2.20)
- Momentum context via ROC indicators
- Moving average structure

BLOCKER / What is NOT reproduced:
- DIAGONAL TRENDLINES: The bull flag pattern requires converging
  diagonal lines drawn over the consolidation zone. EpochScript
  only supports horizontal reference_lines. There is no diagonal
  line, trendline, or freeform annotation capability.
- The flag pattern annotation (the red triangle visible in the
  original chart) cannot be drawn.
- This is a FUNDAMENTAL LIMITATION of the charting system —
  it cannot reproduce discretionary pattern annotations.

Workaround:
- Horizontal reference lines at $2.60 and $2.90 bracket the
  flag consolidation zone, giving approximate visual bounds
- The momentum chart (ROC) quantifies the pattern's energy

Date range override in run_config.json:
  "amfx_rbob_bull_flag_research": {
    "start": "2022-12-01",
    "end": "2023-08-31"
  }
