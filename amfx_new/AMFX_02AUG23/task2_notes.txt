Task 2: API Crude Oil Inventory 2023 (Weekly Bar Chart)
========================================================
Status: IN_PROGRESS — Definition written, not yet run.

Definition: project/definitions/test_runner/amfx_crude_inventory_2023_research.json
Run config override: start=2023-01-01, end=2023-08-31

Data Source
-----------
- FRED series: WCESTUS1 (Weekly U.S. Ending Stocks of Crude Oil, Thousand Barrels)
- Transform: week-over-week change = (current_stocks - prior_stocks) / 1000 → millions of barrels
- Mode: use_alfred=False (index by observation date, Friday week-ending)
- Original chart uses API (American Petroleum Institute) data; we use EIA data from FRED as proxy

Chart Approach
--------------
- Transform: xy_bars
- Labels: YYYYMMDD encoding with Exact category type
- NaN-label pattern: crude_change_m / crude_change_m creates nan_flag; multiply with raw label
  → only release-day bars have non-NaN labels; NaN labels filtered out by Exact type
- color_by_value=True: green for builds (positive), red for draws (negative)
- data_labels=True: shows value on each bar
- Reference line at zero

Known Differences from Original
---------------------------------
1. EIA vs API data source: EIA surveys refiners, API surveys companies. Values will differ by 1-3M barrels typically.
2. X-axis shows YYYYMMDD numbers (e.g., "20230106") instead of month names.
   Original has "Jan 2023", "Feb 2023", etc. with multiple bars per month.
   The Exact category type doesn't support month-name rendering for sub-monthly data.
3. The record -15.4M barrel draw in the original may show as a different magnitude with EIA data.
